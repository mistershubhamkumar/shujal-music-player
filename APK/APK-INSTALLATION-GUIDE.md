# Shujal Music Player — APK Installation Guide

## Included APK File
- `Shujal_Music_Player.apk` — Installable debug build signed with the Android debug keystore.

## How to Install on Android
1. Download `Shujal_Music_Player.apk` to your Android device (Android 7.0 / API 24 or higher).
2. Open the `.apk` file from your device's file manager and allow **Install unknown apps** if prompted.
3. Launch **Shujal Music**.
4. On first open, follow the one-by-one prompts to allow audio scanning, playback notifications, and the optional floating **Dynamic Island** background mini player.
